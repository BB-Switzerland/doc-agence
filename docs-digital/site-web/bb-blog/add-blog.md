# Ajouter un article BB Blog

Une fois connecté dans le back-office rendez-vous dans l'onglet [Articles](https://agence-bb.ch/wp-admin/edit.php)


1. Cliquez sur ***Ajouter*** en haut à gauche.
2. Mettez un **titre**.
3. En **dessous** le **texte** précédemment validé.
4. Puis l'**image** de mise en avant dans les widgets à droite.
5. Ajouter dans les **catégories** à droite la catégorie de votre Use Case.
6. Ajouter les metas (titre, description) relatives à l'article pour le référencement en bas de page ***Extrait de référencement (Snippet)*** > ***Balises méta*** puis ***Sauvegarder***.
7. ***Publier***.


:::warning

Après chaque modification sur le site web, il est **impératif** de vider le cache du site via le menu tout en haut ***WP Rocket*** > ***Vider et précharger le cache***.

Une fois le cache vidé il faut **naviguer** sur le site **sans être connecté à l'administration** pour que le cache se remette sur les pages principales ⚠️ ⚠️.

:::
