# Ajouter un BB Life

Une fois connecté dans le back-office rendez-vous dans l'onglet [BB Life](https://agence-bb.ch/wp-admin/edit.php?post_type=bbslife)

1. Cliquez sur ***Ajouter*** en haut à gauche.
2. Mettez un **titre**.
3. En **dessous** le **texte** précédemment validé.
4. Puis l'**image** du BB Life.
5. Ajouter dans les **étiquettes** à droite l'étiquette de votre BB Life et aussi l'étiquette **"Image"**.

:::info

Il faut que l'***Étiquette BB Life*** **Image** soit attribuée pour que le BB Life s'affiche sur le site ! ⚠️

:::

:::warning

Après chaque modification sur le site web, il est **impératif** de vider le cache du site via le menu tout en haut ***WP Rocket*** > ***Vider et précharger le cache***.

Une fois le cache vidé il faut **naviguer** sur le site **sans être connecté à l'administration** pour que le cache se remette sur les pages principales ⚠️ ⚠️.

:::
