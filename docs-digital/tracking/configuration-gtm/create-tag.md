# Création d'un évènement personnalisé avec GTM pour (GADS)

## Configuration de la balise

Après avoir créer votre déclencheur, il est temps de créer la balise corresondante à votre déclencheur.

### Création de la balise Google Ads

Pour se faire, rendez-vous dans **_Balises_** puis **_Nouvelle_** > **_Google Ads_** > **_Suivi des conversions Google Ads_**

### Configuration des paramètres

Ajouter le **_le conversion ID_** et le **_Conversion Label_**

Puis dans **_Déclenchement_** sélectionnez le déclencheur **_Clic - Contact_**

## Test de la balise

:::note
Vous pouvez tester votre balise via l'extension [**Tag Assisitant**](https://chromewebstore.google.com/detail/kejbdjndbnbjgmefkgdddjlbokphdefk?utm_source=item-share-cb)
:::
