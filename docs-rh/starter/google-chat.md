# 💬 Google Chat

Google Chat est l'outil de communication interne de l'agence. C'est là que se passent les échanges avec tes collègues, les infos importantes et les notifications.

## Te connecter

Pas d'invitation à attendre : Google Chat fait partie de Google Workspace, ton compte de l'agence suffit.

1. Va sur [chat.google.com](https://chat.google.com).
2. Connecte-toi avec ton adresse **@agence-bb.ch**.

Tu le retrouves aussi dans Gmail, dans le panneau de gauche.

:::tip
Installe l'application sur ton téléphone : les notifications y sont bien plus fiables que dans l'onglet du navigateur.
:::

Un souci pour entrer ? Écris à ton manager.
