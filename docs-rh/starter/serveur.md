# 🖥️ Serveur & VPN

## Serveur Général de l'agence

Le serveur général de l'agence est réparti par pôle et accessible à l'adresse suivante :

```
smb://10.1.1.230
```

## Serveur Photos/Videos

Le serveur dédié aux photos et vidéos est accessible à l'adresse suivante :

```
smb://10.1.1.231
```

:::info
Si vous avez des problèmes pour accéder aux serveurs, n'hésitez pas à contacter Amancio pour le serveur général ou Charles pour le serveur photos/vidéos.
:::

:::warning
Pour accéder aux serveurs, vous devez être connecté au réseau de l'agence ou utiliser le VPN.
:::

## Configuration du VPN

Si vous avez reçu des accès VPN par mail, suivez ces étapes :

1. Rendez-vous à cette adresse : [https://vpn.agence-bb.ch:4443/](https://vpn.agence-bb.ch:4443/)
2. Téléchargez le fichier de configuration
3. Importez ce fichier dans **OpenVPN**

:::tip
Une fois le VPN configuré, vous pourrez accéder aux serveurs de l'agence depuis n'importe où !
:::
