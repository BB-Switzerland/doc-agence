# 🔐 1Password

1Password est l'outil de gestion de mots de passe de l'agence. C'est là que tu trouveras tous les mots de passe pour les différents outils que nous utilisons.

## Accès à 1Password

Tu as dû recevoir un mail avec l'objet `Join amancioluis@agence-bb.ch on 1Password` contenant tes identifiants de connexion. Si tu ne l'as pas reçu, tu peux demander à ton manager de te les renvoyer.

### Pour te connecter:

1. Connecte-toi en cliquant sur le lien dans le mail.
2. Télécharge l'application 1Password sur ton navigateur.
3. Connecte-toi avec tes identifiants.
4. Tu trouveras tous les mots de passe public dans la section `Partagé - BBS`.

:::tip

Assure-toi d'avoir bien installé l'extension 1Password sur ton navigateur pour pouvoir accéder rapidement aux mots de passe 😉.

:::
