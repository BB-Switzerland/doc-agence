# 📋 Monday

Monday est l'outil de gestion de projet de l'agence. C'est là que tu trouveras toutes les informations sur les projets en cours, les tâches à réaliser, les deadlines, etc.

## Accès à Monday

Tu as dû recevoir un mail avec l'objet `[monday.com] Amancio Luis Cougil vous a invité(e) sur le compte monday.com de Agence BB Switzerland` contenant tes identifiants de connexion. Si tu ne l'as pas reçu, tu peux demander à ton manager de te les renvoyer.

### Pour te connecter:

1. Connecte-toi avec ton compte Google en cliquant sur le lien dans le mail.


:::tip

Tu peux utiliser Monday directement dans ton navigateur ou depuis l'application sur ton ordinateur ou ton téléphone.

:::
