# Le CRM en un coup d'œil

Avant les how-to, la carte mentale. Le CRM vit dans le workspace « CRM - BB® » et repose sur six boards qui se répondent.

## Les boards

| Board | Rôle |
|---|---|
| [Prospects / Pistes](https://agence-bb-ensemble.monday.com/boards/5093138638) | Point d'entrée de **tous** les leads |
| [Contacts](https://agence-bb-ensemble.monday.com/boards/5093138641) | Les personnes qualifiées |
| [Comptes](https://agence-bb-ensemble.monday.com/boards/5093138643) | Les entreprises clientes et prospects |
| [Opportunités](https://agence-bb-ensemble.monday.com/boards/5093138639) | Les deals : devis, négociation, signature |
| [Services - BB®](https://agence-bb-ensemble.monday.com/boards/5095856027) | Le catalogue des prestations (≈ 110) — **lecture seule** |
| [Activités CRM](https://agence-bb-ensemble.monday.com/boards/5093138642) | Appels, meetings, relances |

S'y ajoute le board **Satisfaction clients**, qui héberge les enquêtes.

## La chaîne de valeur

:::tip Le LEAD est la source de tout
Tout part de la piste. On ne crée **jamais** un Contact ou un Compte directement : on **convertit** une piste. Les colonnes miroir remontent ensuite l'information d'un board à l'autre, donc aucune double saisie n'est nécessaire.
:::

Le lead entre dans **Prospects / Pistes** et y est qualifié. Un bouton le transfère dans **Contacts**, où on le rattache à son entreprise dans **Comptes**. Une **Opportunité** est alors créée, reliée au contact et au compte. C'est depuis cette opportunité que l'app **Devis Creator** produit le devis.
